# ECOREAN BOC — Master Plan
최종 확정: 2026-04-25

## 1. 시스템 정의
BOC = Build Operation Center
견적→계약→발주→공정→현장→검수→하자→정산→피드백→DB업데이트 (Closed Loop)

## 2. 핵심 철학
1. 사람이 아닌 시스템이 판단
2. 현장 데이터가 시스템을 성장시킴
3. 대표 승인 없이 DB 변경 불가
4. 모든 데이터가 Neo4j로 순환
5. 버그 없는 구조 (TDD 강제)
6. 100배 확장 가능 구조

## 3. 기술 구조
단일 HTML + 내부 모듈 패턴
CONFIG→CalcEngine→OntologyEngine→DiagEngine
→ScheduleEngine→FinanceEngine
→AppState→Router→UI→INIT
script 블록 1개 / 함수 중복 금지
단방향 데이터 흐름 / 순수 함수
저장: SQLite(운영) + Neo4j(지식) + localStorage(임시)

## 6. 계산 공식
공급가 = qty×(1+wr)×(lb×pm + mt×matMul)
도급 = 공급가×1.15
최종 = 도급×1.10(VAT)
pm: 표준1.0/고급1.3/프리미엄1.7
양중: 5층+8%/10층+15%/15층+20%/엘없음+30%
거주중: +10%

## 7. DB 구조
계단식 4단계: 대분류→중분류→소분류→규격
공간-공정 매핑:
  욕실필수: 방수/바닥타일/벽타일/줄눈/위생도기/천장/환풍기
  주방필수: 바닥재/벽타일/주방가구/후드
  거실필수: 바닥재/도배/천장
온톨로지 26개:
  AUTO: 타일→줄눈, 도배→초배, 바닥재→걸레받이, 창호→우레탄폼
  CONDITIONAL: 방수(직접선택만)
  FORCED: 갈바나이즈→배관교체
