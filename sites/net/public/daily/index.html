공정 태그
BOC 공사일보 — 사용방법

1시작 — 공정표 연동

  • 📂 공정표 불러오기로 공정표 JSON을 올리면, 보고일에 맞춰 진행공정·인원·자재·검측이 자동 표시됩니다.
  • 공정표 없이도 각 항목을 수동으로 작성할 수 있습니다.
  • 상단 건축 / 실내건축 전환으로 공종 팔레트가 바뀝니다.

2매일 작성 순서 (① ~ ⑬)

  • ① 기본정보 — 현장명·주소·현장소장·착공일 (현장소장은 ④에 자동 고정)
  • ② 금일 진행공정 — 보고일 기준 자동추출, 진행률 자동(수정 가능)
  • ③ 체크리스트 — 진행공정 점검 + 발주 임박만 표시 (전체보기 토글)
  • ④ 투입인원 — 공정 인력으로 적정인원 자동, 직종은 드롭다운+직접입력, 현장소장 고정
  • ⑤ 명일예정 · ⑥ 자재 — 자동 + ＋수동추가
  • ⑦ 장비 · ⑧ 안전(TBM) · ⑨ 검측(감리) · ⑩ 특이사항
  • ⑪ 고객협의 · ⑫ 현장사진 · ⑬ 현금출납부 (전일잔액 자동 이월, 지출은 공정 귀속)

3보고일 바꾸기

  • 보고일을 바꾸면 그날 공정 기준으로 자동 갱신됩니다.
  • 작성 중이던 내용은 자동 저장되어 날짜를 옮겨도 사라지지 않습니다.

4저장 · 내보내기

  • 입력은 브라우저에 자동 저장됩니다. 💾 JSON 저장은 전체 백업용입니다.
  • 📄 일보 HTML 내보내기 = 그날 일보 1개 파일 (인쇄용 + 데이터 내장).
  • 📤 대시보드로 전송 = 파일 없이 한 번에 대시보드로 보냄 (같은 브라우저/사이트에서 대시보드가 자동 반영).
  • 이 일보 파일들을 프로젝트 대시보드에 모으면 현금·인원·공정률이 자동 집계됩니다.
💡 자동으로 채워진 값은 언제든 고칠 수 있고, 고친 값은 다시 추출해도 보존됩니다. 사진은 기기에만 저장되어 JSON 백업에는 포함되지 않습니다.
