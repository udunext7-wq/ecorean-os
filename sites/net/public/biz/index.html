카카오톡 연동

이번 달 결산을 공유하거나 내 카톡으로 받기
설정 방법
1. developers.kakao.com 에서 앱 생성
2. [앱 설정]›[앱 키]의 JavaScript 키 복사
3. [앱 설정]›[플랫폼]›[Web]에 이 페이지 도메인 등록
4. (나에게 보내기는) [카카오 로그인] 활성화 + 동의항목 '카카오톡 메시지 전송' 추가
⚠ 도메인 등록이 필요해, 파일을 그냥 열면(file://) 동작하지 않습니다. 웹에 올린 뒤 그 주소를 카카오에 등록해야 합니다.

노션(Notion) 연동

거래 내역을 노션 데이터베이스로 동기화
노션 표 속성(컬럼)을 아래처럼 만들고, 통합을 표에 연결하세요.
내용 → 제목(Title) 금액 → 숫자(Number) 유형 → 선택(Select) [수입/지출] 카테고리 → 선택(Select) 날짜 → 날짜(Date)
⚠ 브라우저 보안(CORS)상 프록시를 경유하므로 토큰이 제3자를 지납니다. 이 가계부 DB에만 통합 권한을 주세요. 안전을 원하면 CSV 내보내기로 노션에 가져오는 방식을 권장합니다.
